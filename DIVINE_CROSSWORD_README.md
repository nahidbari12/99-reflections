# Divine Crossword

Divine Crossword is a new static learning game for the 99 Reflections website.

## Game experience

- Generates a fresh connected crossword on every new game
- Randomly uses 9 or 10 Names of Allah
- Mixes meaning clues with concise reflection based descriptions
- Accepts English transliterations without spaces, apostrophes, or hyphens
- Supports touch, mouse, and physical keyboards
- Across and Down clue navigation
- Active word and cell highlighting
- One letter hints and full answer reveal
- Immediate incorrect word feedback
- Timer, solved counter, score, and completion summary
- Responsive two panel desktop layout and mobile stacked layout

## Learn Mode integration

- Incorrect answers and hints are saved to the unified learning profile
- Missed Names are marked for spaced review
- Results show every Name that needs strengthening
- Review buttons open the exact Name in Smart Learn
- Gamer Mode statistics record plays and best score
