# Divine Crossword 1.1

This release upgrades Divine Crossword while keeping 99 Reflections fully static and compatible with GitHub Pages and Replit.

## New game experiences

- Easy, Medium, and Hard difficulty levels
- Random, Daily, Personalized, and Theme puzzle journeys
- Deterministic Daily Crossword with a completion streak
- Saved unfinished puzzles that continue after closing the page
- Progressive Arabic and letter hints, Check Word, and optional spoken Arabic clues
- Easy-mode word bank and starting letters
- Pause, Fit Puzzle, zoom, fullscreen, automatic cell focusing, and an on-screen mobile keyboard
- Independent, hinted, and review-needed result categories
- Crossword achievements, best-time tracking, and privacy-safe result sharing
- Missed and assisted Names feed into the unified learning profile and link directly to focused Smart Learn review

## Verification

- 60 automated tests pass across 12 test files
- Production build succeeds
- Static SEO generation succeeds with 99 Name pages and 116 sitemap URLs

## Upload to Replit

Extract the ZIP, upload the contents to Replit, run `npm install`, then run `npm run dev`.
