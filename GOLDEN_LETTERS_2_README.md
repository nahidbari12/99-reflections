# Golden Letters 2.0

This release rebuilds Golden Letters as a guided Arabic writing course while preserving static hosting compatibility.

## New experience

- Personalized Golden Letters dashboard with Continue Learning and Today's Practice
- Four destination navigation: Home, Learn, Practice, and Progress
- Guided six step lesson: Learn, Watch, Trace, Faded Trace, Write, and Check
- Submit based writing feedback with shape coverage and guide proximity scoring
- Guided, faded, and independent writing modes
- Undo, Clear, and Show Me canvas controls
- Similar letter recognition checks
- Daily, letter, word, Names of Allah, and phrase practice
- Mastery based alphabet map with New, Learning, Mastered, and Review states
- Writing accuracy, streak, recent attempt, and mastery reporting
- Normal and slow device Arabic speech with graceful fallback
- Responsive phone first lesson and canvas design
- Reduced motion and keyboard focus accessibility support

## Compatibility

- Static React and Vite build
- GitHub Pages compatible
- Replit compatible
- No server or account required
- Existing local Golden Letters progress is retained and migrated
