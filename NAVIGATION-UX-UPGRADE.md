# Navigation UX Upgrade

This release removes the redundant Mode Selection step from normal journeys.

## Updated experience

- Home, Dashboard, Learn, Games, and Quiz remain directly accessible from mobile navigation.
- The homepage opens the Learning hub directly and includes a featured or recently played game shortcut.
- Learn and Games remain organized hubs for activities that require browsing.
- Daily Quiz, Daily Challenge, Learn, Games, and results screens return users to the correct context.
- Nested pages keep the correct bottom-navigation section highlighted.
- Existing `/mode-selection` bookmarks redirect safely to the Learning hub.

## Verification

- Navigation, redirect, active-state, homepage, mobile, game, quiz, and learning tests are included in the complete suite.
